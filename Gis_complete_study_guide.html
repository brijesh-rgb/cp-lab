What is Geographic Information System (GIS)?
PYQ 2022 2023 2024 6 Marks ›

Definition

A Geographic Information System (GIS) is a computer-based system designed to capture, store, manipulate, analyze, manage, and display all types of geographically referenced data. It integrates hardware, software, data, people, and procedures to help organizations make informed, location-based decisions.

Dueker & Kjerne: "GIS is a system of hardware, software, data, people, organizations and institutional arrangements for collecting, storing, analyzing and disseminating information about areas of the earth."

In simple terms, GIS is a smart map — it not only displays WHERE things are, but also WHAT they are, WHY they are there, and WHAT WILL HAPPEN if conditions change.

TransportationRoute optimization, traffic analysis, logistics

Components of GIS
PYQ 2022 2024 6 Marks ›

GIS consists of 5 major components that work together to form a complete functional system for spatial data management.

Five Components of GIS

1. Hardware

Input: Digitizers, Scanners, GPS receivers, Remote sensing satellites. Processing: Workstations, Servers. Output: Plotters, Monitors, External storage.

2. Software

Provides tools to store, analyze, and display geographic data. Examples: ArcGIS (commercial), QGIS (open source), MapInfo, GRASS GIS, PostGIS.

3. Data

Most critical component. Spatial data — location coordinates (points, lines, polygons). Attribute data — descriptive properties (name, population, area).

4. People

GIS Specialists (analysts), Database Administrators, End Users (planners, government officials), Programmers (custom app developers).

5. Methods / Procedures

Rules and workflows for data collection, analysis, map production standards, and quality control procedures.

Types of Vector Data
PYQ 2022 2023 6–8 Marks ›

Vector data represents geographic features using geometric shapes (points, lines, polygons) defined by coordinate pairs (X,Y). It is precise, compact, and ideal for discrete features.

Three Types of Vector Data

1. Point Data

Represents a single location with coordinates (X, Y). No dimension (0D). Used for features too small for their scale. Examples: cities on small-scale map, wells, hospitals, GPS waypoints.

2. Line / Polyline Data

A series of connected points forming a linear feature. Has length (1D) but no area. The start and end points are different. Examples: roads, railways, rivers, contour lines, pipelines.

3. Polygon Data

A closed shape with three or more vertices where start = end point. Has both area and perimeter (2D). Examples: country boundaries, lakes, forests, building footprints, land parcels.

TypeDimensionPropertiesExamples
Point0DLocation onlyWell, City, Hospital
Line1DLengthRoad, River, Railway
Polygon2DArea + PerimeterDistrict, Lake, Forest

Elements of Vector Data (PYQ 2023)

  • Nodes: Start and end points of a line/arc
  • Vertices: Intermediate points along a line
  • Arcs/Edges: Line segments connecting nodes
  • Polygons: Closed regions formed by arcs
  • Attributes: Non-spatial data associated with features
  • Topology: Spatial relationships between features
  • Coordinates: X, Y (and optionally Z) values
Raster Data Model & Types
PYQ 2022 2023 2024 6–8 Marks ›

A raster data model represents geographic space as a regular grid of cells (pixels), where each cell holds a single value representing an attribute at that location.

Key Characteristics: Cell (pixel) · Cell Size (Resolution) · Cell Value · Extent (Bounding Box) · Rows & Columns · Bands · NoData Value · Coordinate Reference System
Raster Grid Structure

Advantages of Raster Data

  • Simple data structure — easy to analyze
  • Compatible with satellite and aerial imagery
  • Efficient for surface/continuous data analysis (slope, aspect)
  • Easy overlay operations
  • Supports spatial modeling easily

Disadvantages of Raster Data

  • Large file sizes — high storage requirement
  • Resolution-dependent — lower resolution = less accuracy
  • Cannot represent sharp or irregular boundaries well
  • Network analysis is difficult in raster
  • Loss of precision with coarser resolution

TIN Data Model (Triangulated Irregular Network)
PYQ 2022 2023 2024 6 Marks ›

A TIN (Triangulated Irregular Network) is a vector-based 3D terrain model formed by a network of non-overlapping triangles. Each triangle has three nodes with X, Y, Z (elevation) coordinates connected using Delaunay Triangulation.

TIN Structure — Nodes, Edges & Faces

Structure of TIN

ElementDescription
NodesPoints with X, Y, Z coordinates (elevation values)
EdgesLines connecting adjacent nodes (triangle sides)
FacesTriangular surfaces formed by three nodes

Delaunay Triangulation

Algorithm used to build TIN — ensures no point lies inside the circumcircle of any triangle, maximizing equilateral triangles and avoiding long thin shapes.

  • Terrain/3D surface modeling (hills, valleys, mountains)
  • Flood prediction and watershed analysis
  • Civil engineering — road and building design
  • Volume calculation (cut and fill in construction)
  • Military — line-of-sight analysis

Raster Data Compression Techniques
PYQ 2022 2023 2024 6–8 Marks ›

Raster data files can be very large. Compression techniques reduce storage requirements while maintaining data usability. The main techniques are:

1. Run-Length Encoding (RLE)

Stores consecutive cells with the same value as a single record (value, count) instead of repeating them.

Original: 1,1,1,1,2,2,3,3,3,3,3
RLE: (1×4), (2×2), (3×5) → saves 4 values
Run-Length Encoding (RLE)

2. Chain Coding

Represents boundaries of features by recording the direction of movement from one cell to the next using direction codes (0–7 for 8 directions). Used to compress line/boundary features efficiently.

Directions: 0=E, 1=NE, 2=N, 3=NW, 4=W, 5=SW, 6=S, 7=SE
A polygon boundary: Start(2,1) → 0,0,2,2,4,4,6,6 (chain code)

3. Block Encoding (Block Code)

Similar to RLE but works in 2D. Divides the area into the largest possible square blocks of uniform value. More efficient for areas with large uniform zones.

Record format: (Row, Col, BlockSize, Value)
Example: (1,1,2,"Forest") = 2×2 block starting at row 1, col 1, all Forest

4. Quadtree Encoding

Hierarchical subdivision — the entire raster is recursively divided into 4 quadrants until each quadrant has a uniform value. Most complex but most efficient for sparse data.

Quadtree Division

Comparison

TechniqueWorks onBest ForComplexity
RLE1D rowsUniform horizontal regionsLow
Chain CodingBoundariesLine/polygon outlinesMedium
Block Encoding2D blocksLarge uniform zonesMedium

Raster Data File Formats
PYQ 2024 6 Marks ›

Raster data is stored in various file formats depending on the use case. The three most common formats used in GIS are:

1. GeoTIFF (.tif)

Most widely used raster format in GIS. It is a standard TIFF image file with embedded geospatial metadata (coordinate system, projection, extent). Supports single and multi-band data.

Use cases: Satellite imagery, DEMs, aerial photography, remote sensing outputs

2. JPEG2000 (.jp2)

Advanced compression format based on wavelet technology. Provides high compression ratios with minimal quality loss. Supports georeferencing through world files or internal metadata.

Use cases: Web mapping, large satellite image archives, efficient storage

3. ASCII Grid (.asc)

Simple text-based raster format. Header contains metadata (rows, cols, cell size, nodata value), followed by a matrix of cell values. Easy to edit manually but no compression.

Use cases: DEM exchange, hydrological modeling, academic research data sharing

Other Common Formats

HDF5.h5Hierarchical, NASA satellite data

Key Terminologies

  • Geometry: Shape and location stored as WKT/WKB (e.g., POINT(72.87 19.07))
  • Spatial Index: R-Tree, Quad-Tree for fast spatial searches
  • Spatial Functions: ST_Area(), ST_Buffer(), ST_Distance(), ST_Intersects()
  • Topology: Rules defining spatial relationships (Contains, Within, Touches)
  • CRS: Coordinate Reference System (WGS84/EPSG:4326)
  • Primary/Foreign Key: Table relationships for joined attribute data
  • Metadata: Data about the spatial dataset (source, accuracy, date)
Best for GIS Analysis: PostGIS is considered most suitable for GIS analysis due to its open-source nature, full support for OGC standards, powerful spatial functions, and seamless integration with QGIS and web GIS frameworks.

Pre-processing of Spatial Datasets
PYQ 2022 2023 6–8 Marks ›

Pre-processing involves preparing raw spatial data before analysis to ensure accuracy, consistency, and compatibility. It is a critical step in GIS workflows.

Pre-processing Pipeline

Steps in Pre-processing

  • 1. Data Collection & Import: Gathering data from GPS, satellites, digitizers, existing maps
  • 2. Format Conversion: Converting between formats (e.g., shapefile to GeoJSON, paper map to digital)
  • 3. Coordinate System / Projection: Transforming data to a common CRS for all layers
  • 4. Error Detection & Correction: Identifying and fixing geometric errors (gaps, overlaps, dangles, sliver polygons)
  • 5. Resampling: Changing raster cell size to match other layers
  • 6. Clipping/Masking: Extracting data for specific study area extent
  • 7. Attribute Cleaning: Fixing null values, duplicate records, inconsistent naming
  • 8. Topology Validation: Ensuring spatial relationships are correct
Map Projections in GIS
PYQ 2022 2023 2024 6–8 Marks ›

A map projection is a mathematical method of representing the curved 3D surface of the Earth on a flat 2D map. Every projection causes some distortion of shape, area, distance, or direction.

Three Types of Projection Surfaces

Common Projections Used in GIS

  • WGS84 (EPSG:4326): Global GPS standard, geographic coordinates
  • UTM (Universal Transverse Mercator): Local/regional mapping, minimizes distortion
  • Mercator: Web maps (Google Maps), navigation
  • Lambert Conformal Conic: Aviation charts, US state plane
  • Polar Stereographic: Arctic/Antarctic mapping
Spatial Interpolation Techniques (IDW & Kriging)
PYQ 2024 6 Marks ›

Spatial interpolation estimates unknown values at unsampled locations based on known values at surrounding sampled points. Essential for creating continuous surfaces from point data.

1. Inverse Distance Weighting (IDW)

IDW assumes nearby points have more influence than distant ones. The weight of each known point is inversely proportional to its distance from the unknown point.

Z(x) = Σ [Z(xi) / d(x,xi)^p] / Σ [1 / d(x,xi)^p]
where d = distance, p = power parameter (usually 2), Z = value
Best scenarios: Rainfall estimation, temperature interpolation, pollution mapping — where closer stations are more relevant

2. Kriging

Kriging is a geostatistical method that uses a semivariogram to model spatial autocorrelation. It provides the best linear unbiased estimate (BLUE) along with error estimates at each point.

Z(x) = Σ λi · Z(xi)
where λi = optimal weights derived from the semivariogram
Best scenarios: Groundwater elevation, soil properties, mineral exploration — where spatial autocorrelation structure is known

Types of Spatial Resolutions in GIS
PYQ 2022 2023 6–8 Marks ›

Resolution in GIS refers to the level of detail in spatial data. There are four main types of resolution:

TypeDefinitionExamples
Spatial ResolutionSize of smallest feature detectable (pixel size on ground)Landsat = 30m, Sentinel = 10m, Ikonos = 1m
Spectral ResolutionNumber and width of wavelength bands capturedRGB (3 bands), Multispectral (8 bands), Hyperspectral (200+ bands)
Temporal ResolutionFrequency of data collection (revisit time)Landsat = 16 days, MODIS = daily, SPOT = 26 days
Radiometric ResolutionNumber of brightness levels per pixel (bit depth)8-bit = 256 levels, 16-bit = 65536 levels
There is a trade-off: Higher spatial resolution → smaller coverage area → larger file size. Satellites balance all four resolutions based on their mission.
Digital Elevation Model (DEM)
PYQ 2023 2024 6 Marks ›

A Digital Elevation Model (DEM) is a raster representation of terrain elevation — a digital 3D representation of the Earth's surface. Each cell contains the elevation value (Z) of that location above sea level.

DEM vs DSM vs DTM: DEM = bare earth surface | DSM = surface including buildings and trees | DTM = terrain with drainage features

Sources of DEM Data

  • SRTM (Shuttle Radar Topography Mission) — 30m / 90m resolution, free
  • ASTER GDEM — 30m resolution, global coverage, free
  • LiDAR — very high resolution (0.5m–5m), expensive
  • Photogrammetry from aerial photography
  • Digitized contour maps

Applications of DEM

  • Slope and aspect analysis
  • Watershed delineation and hydrological modeling
  • Flood inundation mapping
  • Viewshed analysis (line of sight)
  • Road and pipeline route planning
  • Volume calculation for excavation/fill
  • 3D visualization and fly-through
  • Landslide susceptibility mapping

Quality Assessment of GIS & Freely Available DEMs
PYQ 2022 2024 6 Marks ›

Quality assessment in GIS ensures that spatial data is accurate, consistent, and fit for its intended purpose. Poor quality data leads to incorrect analysis and decisions.

Dimensions of GIS Data Quality

DimensionDefinitionHow to Measure
Positional AccuracyHow close features are to true locationRMSE against GPS/survey
Attribute AccuracyCorrectness of non-spatial dataField verification, cross-checking
CompletenessAll required features presentCompare with reference dataset
Logical ConsistencyTopological correctnessTopology rules validation
Temporal AccuracyData is current and up-to-dateDate of data collection
LineageHistory/source of dataMetadata documentation

Quality Assessment of Freely Available DEMs (SRTM, ASTER)

  • Vertical Accuracy Check: Compare DEM elevations against known GPS benchmarks or surveyed points using RMSE
  • Artifact Detection: Identify data voids (missing values), striping, speckle noise
  • Resolution Adequacy: 30m SRTM vs 1m LiDAR — check if scale is suitable for the study
  • Vegetation Bias: SRTM captures top of vegetation, not bare earth in forest areas
  • Comparison with LiDAR: High-accuracy LiDAR used as reference ground truth
  • Hydrological Plausibility: Check that rivers flow downhill, no flat sinks
Steps Involved in GIS Analysis
PYQ 2024 6 Marks ›

GIS analysis follows a systematic process to solve spatial problems and derive meaningful information from geographic data.

GIS Analysis Workflow
  • Step 1 — Problem Definition: Clearly define the spatial question/objective (e.g., find best site for a school)
  • Step 2 — Data Collection: Gather relevant spatial and attribute data from multiple sources
  • Step 3 — Data Pre-processing: Clean, convert, reproject, and validate the data
  • Step 4 — Spatial Analysis: Apply overlays, buffers, queries, interpolation, network analysis
  • Step 5 — Output/Visualization: Generate maps, charts, 3D views, reports
  • Step 6 — Decision Making: Interpret results and make location-based decisions

Errors in GIS Applications
PYQ 2022 2023 2024 6 Marks ›

Errors in GIS can occur at any stage — data collection, processing, or output. Identifying and minimizing errors is critical for reliable GIS analysis.

Types of Errors in GIS

Error TypeDescriptionExample
Positional ErrorFeature not in true geographic locationRoad shifted by 50m from actual position
Attribute ErrorWrong or missing descriptive dataPopulation count incorrectly entered
Topological ErrorIncorrect spatial relationshipsGaps, overlaps, sliver polygons, dangling nodes
Scale ErrorFeatures not correctly scaledMixing 1:25000 and 1:250000 data
Temporal ErrorData from different time periodsOld road network with new satellite image
Digitizing ErrorManual input mistakesUndershoot, overshoot, wrong feature type
Projection ErrorWrong CRS assigned or usedData shifted due to wrong datum

Areas Where Errors Are Encountered

  • Data Input: Digitizing errors, scanning artifacts, GPS measurement errors
  • Data Processing: Resampling errors, interpolation inaccuracies, overlay errors
  • Data Storage: Precision loss during format conversion
  • Data Output: Map generalization, scale-related errors
  • Application: Using wrong methodology for analysis

Impact on GIS Analysis

Errors propagate through analysis — a positional error in one layer multiplies through overlay operations, leading to incorrect site selection, wrong boundary delineation, or flawed resource allocation decisions.

Mitigation: Quality control checks at every stage, metadata documentation, cross-validation with field data, using appropriate scale data for analysis.
Key Elements of a Map
PYQ 2022 2023 2024 6 Marks ›

A map must contain certain essential elements to be useful and interpretable. These elements provide context and reference for the spatial information shown.

Key Elements of a Map

All Key Elements

  • Title: Clearly identifies what the map represents
  • Map Body: The actual geographic content with features
  • Legend / Key: Explains symbols, colors, and patterns used
  • North Arrow / Compass Rose: Shows orientation/direction
  • Scale Bar / Representative Fraction: Shows distance relationship (e.g., 1:50,000)
  • Inset / Location Map: Shows study area in regional context

  • Contour Lines: Lines connecting equal elevation points
  • Data Source & Date: Metadata about data origin and currency
  • Author / Publisher: Who created the map and when
  • Projection Information: Which map projection was used
Vector Overlay in Polygon (Impose, Stamp, Join, Compare)
PYQ 2024 6 Marks ›

Vector overlay is a GIS operation that combines two or more polygon layers to create a new layer containing the spatial and attribute characteristics of all input layers. It answers "what is at this location from multiple layers?"

Vector Overlay Types
  • Impose: Layer B is placed over Layer A — both remain unchanged; used for visual inspection
  • Stamp: Layer B is "stamped" into Layer A — B attributes are transferred to overlapping regions of A
  • Join: Attributes from B are added to A's table based on spatial coincidence — no new boundaries created
  • Compare: Spatial differences between two time-period layers are identified — used for change detection (e.g., deforestation mapping)

2023 Q5CWhich of these is spatial data? Justify [6 marks]
Answer

a. Elevation of Mount Everest (8,849m) — Spatial: YES. It has a specific geographic location (lat/long of Everest summit) + elevation value (Z).

d. Location (lat, long) of an oil well — Spatial: YES. This is the most purely spatial — it directly gives coordinates as spatial data.
